# Слагтерра: Дуэли

Одностраничная игра для двух игроков. Весь игровой интерфейс работает как статический HTML/JavaScript, без игрового сервера и регистрации. В оформлении используются авторские карточки слагов и рубашка из папки «карточки слагов».

## Публикация на GitHub Pages

1. Поместите `index.html`, `README.md` и всю папку `assets` в корень репозитория GitHub и отправьте их в ветку `main`. В `assets` находятся оформление и оптимизированные изображения; сохраняйте структуру подпапок.
2. Откройте в репозитории **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/(root)`, затем нажмите **Save**.
4. После публикации откройте адрес сайта на компьютере и начните дуэль. На GitHub Pages адрес сайта определяется автоматически; QR-коды появятся после перемешивания слотов.

GitHub Pages поддерживает публикацию сайта из корня выбранной ветки; точные пункты настройки описаны в [документации GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

## Карточки и оформление

Новые карточки показаны целиком в сборе колоды, личном HUD и использованных ячейках арены. Все закрытые и замороженные ячейки показывают новую рубашку. Для просмотра текста крупнее используйте кнопку «Рассмотреть карту» в сборе колоды или нажмите карточку в личном HUD / использованной ячейке.

Игра загружает небольшие изображения `assets/cards/<id>.jpg` (480 × 679), а крупные `assets/cards/<id>-large.jpg` (1000 × 1415) — только при открытии просмотра. Оригиналы в папке «карточки слагов» сохранены; для публикации нужны оптимизированные копии в `assets`. Рубашка находится в `assets/cards/back.jpg`, оформление — в `assets/card-redesign.css`.

При обновлении уже опубликованной игры загрузите новый `index.html` и папку `assets` через **Add file → Upload files** в репозитории, затем сохраните изменения. После публикации обновите страницу на компьютере и телефонах.

## Запуск до публикации

Откройте `index.html` и в блоке QR укажите полный HTTPS-адрес опубликованной страницы, например `https://имя.github.io/slugterra/`. Адрес сохраняется в этом браузере. Телефон открывает HUD по QR-ссылке с GitHub Pages; файл `file://` на телефоне не нужен.

Каждый раунд формирует новые QR-коды для обеих перемешанных колод. После того как Светляк или Гипно разведает ячейки, пересканируйте обновлённый код своего игрока, чтобы увидеть эти сведения в разделе разведки.

## Приватность

На общей арене обе неиспользованные колоды остаются закрытыми. Личный HUD показывает игроку его шесть карт и их номера слотов. Игровое состояние не отправляется на отдельный сервер. Ссылка и QR-код содержат порядок карт в параметрах URL, поэтому не пересылайте их сопернику и не публикуйте. Кнопка **«Скрыть колоду на экране»** убирает карты с телефона до следующего просмотра.

Для QR используется клиентская библиотека [qrcodejs 1.0.0 на cdnjs](https://cdnjs.com/libraries/qrcodejs); при недоступности CDN игра продолжает работать, а под QR остаётся ссылка на личный HUD.
